Tecnologia — CaraCore Hub

Stack local e autonomia operacional

Backend

Java 11 e Jakarta EE 10. Aplicação modular (core, persistence, api, web). Servidor de aplicações: Apache Tomcat ou WildFly. API REST (JAX-RS/Jersey) para integrações e front-end JSP para a interface de gestão.

Banco de dados

O destino público (instalador Windows, 06/04/2027) usa SQLite no computador do cliente. A oficina web atual ainda opera com PostgreSQL (Redis opcional para cache). Não trate “apenas SQLite” como o estado do WAR de desenvolvimento.

Integrações e cache

Integração com marketplaces (Mercado Livre, Shopee, Temu) via API e webhooks. Notificações por WhatsApp quando configuradas. Redis é cache opcional na oficina web atual.
