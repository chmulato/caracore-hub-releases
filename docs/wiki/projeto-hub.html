Gestão de encomendas para centros de distribuição

Oficina privada Licença proprietária GA instalador 06/04/2027 Jakarta EE 10 WAR / Tomcat
Pré-lançamento

A vitrine e os artefatos (WAR) já estão nesta loja. O lançamento público do instalador Windows está previsto para 06 de abril de 2027. A oficina já tem a aplicação web 2.1; isso ainda não é oferta madura nem SaaS público.

O que é o Hub

Para quem opera o centro

Quem vende no Mercado Livre, na Shopee e na Temu costuma abrir três painéis para o mesmo tipo de pedido. O Hub junta a fila, o mapa de estoque e a conferência na retirada.

  • Pedidos multi-marketplace numa fila só
  • Mapa de posições (rua / módulo / nível / caixa)
  • Inventário cíclico e etiquetas
  • Aviso no WhatsApp quando um volume atrasa

Não é a “central telefônica” da Cara Core nem um orquestrador Flask. Isso é mistura com a Área 51.

Stack real

Oficina caracore-hub (repositório privado). Aplicação web: Jakarta EE 10, WAR, Tomcat 10.1, JSP/JSTL, Bootstrap 5, Chart.js. PostgreSQL e Redis no ambiente atual da oficina. Destino público de 2027: SQLite local (Bunker), com envelope desktop já esboçado na oficina (Electron + Tomcat embutido).

  • Perfis RBAC: ADMIN, SUPERVISOR, OPERADOR
  • Conectores: Mercado Livre, Shopee, Temu
  • Notificações: WhatsApp (Evolution API)
  • CTA público: hub.caracore.com.br — nunca /delivery/hub
