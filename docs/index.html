O que é o CaraCore Hub?

Gestão logística e e-commerce para centros de distribuição — recebimento, triagem, estoque, retirada e integração com marketplaces.

O CaraCore Hub 2.1 organiza pedidos, estoque, etiquetas, inventário e retirada para centros de distribuição, com integrações com Mercado Livre, Shopee e Temu. A oficina web usa PostgreSQL e Redis opcional; o futuro instalador Bunker levará SQLite para o computador do cliente.

CaraCore Hub

Aplicação web 2.1 concluída para gestão de encomendas, estoque, etiquetas, inventário e retirada. Instalador Windows com SQLite local planejado para 06/04/2027.

O que é o CaraCore Hub?

O CaraCore Hub 2.1 é um sistema de gestão para centros de distribuição e operações de e-commerce: pedidos, triagem, alocação, mapa de ocupação, etiquetas, inventário, retirada e integrações com Mercado Livre, Shopee e Temu. A aplicação web está concluída na oficina e roda como WAR/Tomcat. O instalador Windows com SQLite local é uma oferta futura; a vitrine não vende um SaaS público já no ar.

Autonomia local

A base SQLite do futuro instalador foi validada na oficina, incluindo as migrações do sistema. A oferta pública de 06/04/2027 usará Electron, Tomcat embutido e SQLite em modo WAL, sem Docker ou PostgreSQL no computador do cliente. Hoje, a aplicação web da oficina usa PostgreSQL e Redis opcional.

Negócios aplicáveis

O CaraCore Hub é aplicável a operações de e-commerce e centros de distribuição. O Programa Tias Sócias fica disponível apenas como cenário ilustrativo de última milha; não é produto, case ou prova de mercado. Ver cenário ilustrativo.
